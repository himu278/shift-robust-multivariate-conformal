# Data

Not stored in Git. Download once and put the file in this folder:

1. https://archive.ics.uci.edu/dataset/189/parkinsons+telemonitoring → **Download**
2. Unzip and copy `parkinsons_updrs.data` here, so the path is `data/parkinsons_updrs.data`.

Source: Tsanas, Little, McSharry & Ramig (2009), UCI Machine Learning Repository (dataset 189).
5875 records, 16 voice features, response = (motor_UPDRS, total_UPDRS).
